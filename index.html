Check equivalence of regular expressions

Syntax
ExpressionMeaning
a | bUnion. Either side may be empty, so a| matches a or nothing.
a bConcatenation.
a?Zero or one copy.
a*Zero or more copies.
a+One or more copies.
a^NExactly N copies. Every digit right after ^ is part of N.
a^{N}†The same, but the braces end the count, so 1^{2}3 is 113.
( a )Grouping. () is the empty string.
ε†The empty string.
Σ†Any one letter of the alphabet. If Σ = {0, 1}, then Σ means (0|1).
0–9†Ordinary letters, except inside a count.
\x†The character x itself, as in \*, \ε, \Σ, or \  for a space.
spaceIgnored, except that it ends a count, so 1^2 3 is 113.

Operators are listed from loosest to tightest binding. The Σ box takes letters separated by commas or spaces, such as 0, 1, 2; braces are optional. Leave it empty and Σ is every letter that appears in R₁ or R₂.
