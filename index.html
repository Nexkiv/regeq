Regular Expression Equivalence

RegEq, with digits and ε

Enter two regular expressions R₁ and R₂. The checker decides whether they describe the same language and, if they don’t, gives the shortest string that separates them. Any character may be a letter, including digits, and ε denotes the empty string.

Syntax

ExpressionMeaning
a | bUnion. Either side may be empty, so a| matches a or nothing.
a bConcatenation.
a?Zero or one copy of a.
a*Zero or more copies.
a+One or more copies.
a^NExactly N copies. Every digit right after ^ is part of N.
a^{N}†The same, but the braces end the count, so 1^{2}3 is 113.
( a )Grouping. () is the empty string.
ε†The empty string. Write \ε for a literal ε.
0–9†Ordinary letters, except inside a count.
\x†The character x itself, as in \*, \|, or \  for a space.
spaceIgnored, except that it ends a count, so 1^2 3 is 113.

Operators are listed from loosest to tightest binding. Both expressions are read over a single alphabet Σ: every letter that appears in either one.

† Not in the original RegEq.
