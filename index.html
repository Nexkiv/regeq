RegEq

Check equivalence of regular expressions

optional

Syntax
Expression Meaning
a | b Union. Either side may be empty, so a| matches a or nothing.
a b Concatenation.
a? Zero or one copy.
a* Zero or more copies.
a+ One or more copies.
a^N Exactly N copies. Every digit right after ^ is part of N.
a^{N}† The same, but the braces end the count, so 1^{2}3 is 113.
( a ) Grouping. () is the empty string.
ε† The empty string.
Σ† Any one letter of the alphabet. If Σ = {0, 1}, then Σ means (0|1).
0–9† Ordinary letters, except inside a count.
other† Any other character is a letter too, including { } [ ] . -, so write [01] as (0|1).
\x† The character x itself, as in \*, \ε, \Σ, or \  for a space.
space Ignored, except around counts: a space ends a count, so 1^2 3 is 113, and a count can't contain or start with one.

Operators are listed from loosest to tightest binding. The Σ box takes letters separated by commas or spaces, such as 0, 1, 2; braces are optional. Ranges like 0-9 aren't supported, and a comma, brace, or dash meant as a letter is written \,, \{, \}, or \-. Leave it empty and Σ is every letter that appears in R₁ or R₂.
